# Transportation Project (Python)

This is a simple **Transportation Management System** written in Python.

## Features
- Add vehicle records
- Remove vehicles
- Update vehicle route
- Mark vehicle active/inactive
- List all vehicles
- Calculate total capacity of active vehicles

## Run
```bash
python3 transportation_project.py
```

## Example Use Cases
- College/bus route simulation
- Beginner OOP practice project
- Small assignment/demo for transport scheduling concepts
